# 🎯 AlgoFit: Lógica en Movimiento

**Aprendé a pensar como programador mientras creás tu propia rutina de ejercicios**

Proyecto educativo completo para estudiantes de secundaria con orientación en programación. Combina **pensamiento computacional**, **algoritmos**, **diagramas de flujo** y **programación** con un tema motivador: **ejercicio saludable**.

---

## 🎯 Objetivo del Proyecto

Que los estudiantes de secundaria pasen de **"no sé por dónde empezar"** a **"puedo resolver cualquier problema dividiéndolo en pasos lógicos"**, aplicándolo a un problema real y útil.

Enseñar los fundamentos del **pensamiento computacional** de forma práctica, divertida y corporal.

- **Público**: Estudiantes de 4° y 5° año de secundario
- **Duración**: 90 minutos (charla + taller)
- **Formato**: Charla interactiva + actividades + proyecto práctico

### Competencias que desarrollan
- Descomposición de problemas
- Creación de algoritmos y diagramas de flujo
- Uso de decisiones (IF), repeticiones (WHILE) y subprocesos
- Validación y corrección de errores (debugging)
- Pensamiento lógico aplicado a la vida real

**Público objetivo**: Estudiantes de 4° y 5° año de bachillerato con orientación en programación.


## 📂 Estructura del Repositorio

- **`docs/`** — Guías, guion y documentación
- **`src/`** — Código fuente (PseInt y Python)
- **`actividades/`** — Escape Room, desafíos y plantillas
- **`recursos/`** — Imágenes y materiales visuales
